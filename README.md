# Learning CSS Flexbox — Student Starter

This lab contains six guided demonstrations and four independent challenges. It focuses on rows, columns, alignment, wrapping, and spacing—not full-page layouts.

## Files
- `index.html` — provided page and instructions
- `reset.css` — the same reset file used earlier in Web Design I; do not edit
- `styles.css` — the **only** stylesheet students edit
- `targets/` — reference pictures for four independent challenges

## In class
1. Open the whole folder in Visual Studio Code.
2. Preview `index.html` with Live Preview.
3. Work at the top of `styles.css` during the six instructor-led demonstrations.
4. Complete the four On Your Own challenges independently, comparing the page to each reference picture.
5. Do not edit the provided appearance styles or the reset.

## Key idea
Flexbox arranges direct children of one parent along a row or column. Use Grid later for more complex two-dimensional layouts.
