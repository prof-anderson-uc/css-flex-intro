# Learning CSS Flexbox — Web Design I

This repository is the **starter project** for the introductory Flexbox coding exercise.

## Your workflow
1. Follow the Canvas instructions to make a repository from your instructor's template.
2. Clone your repository and open the whole folder in Visual Studio Code.
3. Open `index.html` with Live Preview.
4. Follow along with Demos 1–6, editing `styles.css` at the top of the file.
5. Complete Challenges 1–4 **on your own**, referring to the target pictures on the page. Optional hints are in Canvas.
6. Commit and push your work with GitHub Desktop. Submit your repository URL as directed in Canvas.

## Important ideas
- Flexbox works by styling the **parent container**, not each individual child.
- `justify-content` acts on the **main axis**; `align-items` acts on the **cross axis**.
- Changing `flex-direction` also changes the axes.
- `gap` creates space between items; `flex-wrap` lets them form additional lines when necessary.
- Flexbox is especially useful for arranging items in **one dimension**. For larger two-dimensional page layouts, we will learn **CSS Grid**.

## Files
- `index.html` — page markup; already complete
- `styles.css` — your practice CSS at the top, provided page styles below
- `targets/` — pictures of the four finished challenge layouts (not code solutions)

Do not edit the target images to make your results look correct. Fix your CSS instead.
